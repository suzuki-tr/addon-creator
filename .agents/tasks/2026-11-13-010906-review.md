## High-level view

Both prior blocking issues are resolved. `ComponentPanel` now calls `t('editor.components.health.maxLabel')` and `t('editor.components.health.defaultLabel')`, and all three locale files have the corresponding keys. `AppShell` reads `locale` from `useUiStore` and switches between `bg-[#FFFBEB]` and `bg-[#F9FAFB]` depending on whether the active locale is `ja-kids`, matching wireframe #07's warm-yellow background.

The `editor.stateGraph.reset` key borrowed for the UV zoom reset button in `TexturePanel` works at runtime — both `ja.json` and `en.json` carry it as `↺ リセット` / `↺ Reset`, which is the right label for a "reset zoom" button. The issue is purely organizational: anyone grepping for all usage of `stateGraph.*` keys will find a reference in the texture panel, not in `StateGraph.tsx`, and may update or delete the key without realizing it drives a second component. A dedicated `editor.appearance.texture.uvReset` key would isolate the dependency.

The `MaterialPanel` select options are behind a double gate (`mode === 'advanced'` for the outer panel, plus the `mode === 'advanced'` condition inside `AppearancePanel` to show the Material tab). Advanced users are more likely to understand `entity_alphatest` as a Minecraft identifier. The shader terms (`Back`, `Front`, `None` for culling; `None`, `Alpha`, `Additive` for blend) are graphics pipeline terms that Japanese Minecraft documentation also typically leaves in English. The fix is mechanical (add option label keys to the locale files), but the user impact is low enough that it does not block shipping.

### UV zoom reset borrows stateGraph key

`AppearancePanel.tsx` line 299:
```tsx
{t('editor.stateGraph.reset')}
```

This renders `↺ リセット` / `↺ Reset`, which is semantically correct for a zoom reset action. The problem is organizational: `editor.stateGraph.*` is the namespace for the StateGraph tab, not the Texture tab. If the stateGraph section is ever extracted, refactored, or if the reset label needs different wording in a zoom context (e.g. "zoom reset" vs "graph reset"), the shared key becomes an obstacle. The fix is to add:

```json
"editor.appearance.texture.uvReset": "↺ Reset"  // en.json
"editor.appearance.texture.uvReset": "↺ リセット"  // ja.json
// ja-kids.json — omit; fallback to ja works
```

### MaterialPanel select options

The four selects in `MaterialPanel` and the mapping-type select in `TexturePanel` use hardcoded option text. The pattern throughout the rest of the codebase is to pass display text through `t()`. Even for technical terms, adding keys allows locale-specific labeling without code changes. The options affected: `UV`, `Triplanar` (texture mapping type); `Back`, `Front`, `None` (culling); `None`, `Alpha`, `Additive` (blend). All five appear in `mode === 'advanced'` paths only.
